# TASK 2 - EXPLORATORY DATA ANALYSIS (EDA)

##  Objective:
The main objective of this task is to perform Exploratory Data Analysis (EDA) on the dataset in order to understand its structure, detect patterns, identify relationships, and generate meaningful business insights. This helps in transforming raw data into useful information for decision-making and business intelligence.

## Dataset Description:
This project uses two datasets:
   - **Raw Dataset**: Contains original unprocessed data with missing values, inconsistencies, and possible outliers.
   - **Cleaned Dataset**: Processed dataset after handling missing values, duplicates, and data formatting issues.

     Both datasets are analyzed to understand the difference between raw and cleaned data and how data cleaning improves analysis quality.

## Steps Performed:-

# 1. Descriptive Statistics:
- Calculated summary statistics such as:
    - Mean
    - Median
    - Standard deviation
    - Minimum and maximum values
- Helps to understand data distribution and central tendencies.
- Applied on both raw and cleaned datasets for comparison.

# 2. Univariate Analysis:
- Analysis of single variables independently.
- Visualizations used:
  - Histograms (to understand distribution of numerical data)
  - Bar charts (to analyze categorical data frequency)
- Helps in identifying:
  - Skewness in data
  - Most frequent categories
  - Data spread

# 3. Multivariate Analysis:
- Analysis of relationships between multiple variables.
- Techniques used:
  - Correlation heatmaps
  - Boxplots for outlier detection
- Helps in understanding:
  - How variables are related
  - Strength of correlation between features
  - Presence of multicollinearity

# 4. Data Visualization:
The following visual tools were used:
- **Histograms** → Data distribution
- **Boxplots** → Outlier detection
- **Heatmaps** → Correlation between numerical features
- **Bar Charts** → Categorical distribution

These visualizations help in better interpretation of complex data patterns.

# 5. SQL Analysis (Business Queries):
SQL queries were written to:
- Perform aggregations
- Filter specific data
- Group data based on categories
- Extract meaningful business insights

## Key Insights:
- Data cleaning significantly improves data quality and analysis accuracy.
- Certain features show strong correlation indicating dependency.
- Outliers were detected in numerical columns using boxplots.
- Some categories dominate the dataset based on frequency analysis.
- Cleaned dataset provides more stable and reliable patterns compared to raw data.
